# MotooriKosuzuEV

## 1.这是什么

这里提供了用于文本价值判断的一系列工具，包括事件要素抽取、相似度的判断、价值计算、热力图输出

## 2.如何使用这个项目

所有的模块不会相互依赖，所以你可以单独使用某个模块。这样是降低耦合度以便于复用和扩展。

模块以py文件形式，在你的Python项目中导入即可。

## 3\.各个模块都有什么功能

similarity\_ev提供了一个simhash计算函数，你只需要输入两个文本就可以自动比对了

H\_func.py提供了一个H函数、一个信息熵计算函数以及一个样例模型，模型使用了THUCNews部分数据进行训练。H函数用于计算本征价值，其中的分类函数可以自己构建，也可以使用本项目提供的。注意：分类函数返回值是一个多标签向量，你可以用numpy的array也可以用list

Elementfinder基于分类器训练算法（全连接神经网络）抽取要素

DomainClassifier.py提供了几个文字->领域向量的映射函数

## 4\.项目依赖

请确保你安装了transformer、keybert、jieba、torch、collections、hashlib

它们具有“读懂任何文字程度的能力”
